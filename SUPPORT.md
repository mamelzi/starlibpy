# Support

## Usage questions

Before requesting help:

1. read the README and relevant documentation;
2. confirm the installed version with
   `python -c "import starlibpy as slp; print(slp.__version__)"`;
3. reduce the problem to a minimal synthetic example;
4. remove all confidential or identifying information.

A useful support request includes:

- Starlibpy version;
- Python version;
- operating system;
- installation method;
- optional dependency groups installed;
- complete traceback;
- minimal reproducible code and synthetic data;
- expected and observed behavior.

## Statistical interpretation

Starlibpy can structure analyses and report diagnostics, but project support
does not replace consultation with a qualified statistician or subject-matter
expert.

## Sensitive reports

Security vulnerabilities and defects that may silently alter scientific
results should follow `SECURITY.md`, not a public support issue.
